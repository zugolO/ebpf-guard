# Формат (табуляция между полями): <id> <файл> <паттерн для grep -F>
#   id      — пункт постановки (буква волны 5.9.7, см. plan.md);
#   файл    — путь относительно каталога этого файла; "-" означает сам
#             run-gate.sh (сверяется по собственному исходнику);
#   паттерн — фиксированная строка (grep -F), которая обязана присутствовать
#             в файле как реально исполняемая печать (echo/pass/fail), а не
#             только в комментарии — комментарии тоже матчатся буквально
#             строкой grep, поэтому паттерны здесь выбраны так, чтобы
#             совпадать именно с текстом pass()/fail()/echo() вызовов.

# нигде не проверяется — то есть исчезает та же дыра, которую эта волна
# закрывает. Обновлять вместе с постановкой волны.
