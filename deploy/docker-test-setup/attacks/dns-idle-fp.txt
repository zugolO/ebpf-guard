# Реестр объяснённых DNS long-label срабатываний за idle-час, волна 5.9.7f
# (находка №83). Формат тот же, что у silent-rules.txt.
#
# Зачем отдельно от silent-rules.txt: тот реестр — про правило, немое за
# ВЕСЬ аптайм. Этот — про обратный случай: правило, которое ЗА IDLE-ЧАС
# сработало (прирост > 0), когда критерий постановки (п.8: DNS long-label
# на idle — 0) требует объяснения каждого экземпляра, а не одного факта
# наличия причины у правила в целом. Прирост четырёх long-label правил
# (dns_tunneling_long_domain, exfil_dns_txt_long_label, netintr_dns_long_label,
# webshell_dns_exfil_long_subdomain) за idle-час — либо 0, либо каждый
# экземпляр (rule_id + comm) имеет строку здесь.
#
# ФОРМАТ: одна строка на пару "<rule_id> <comm> <категория>", без хвостовых
# комментариев на той же строке (пояснение — отдельным блоком выше списка).
# Категории:
#   a — резолв длинного имени штатен для этого процесса/контейнера (сервис,
#       чьё собственное имя/адрес превышает порог длины лейбла) — объяснение
#       обязано называть, ПОЧЕМУ это имя длинное, а не просто "бывает".
#   b — тестовый/позитивный контроль (5.9.5c run_dns_long_label_attack) —
#       ожидаемое срабатывание, не FP.
#
# ─────────────────────────────────────────────────────────────────────────────
# разобрано: битый вход, не FP (5.9.8h, находка №94, см. plan.md 5.9.8a).
# №2.9.7 дал первый прогон с Details.dns.qname (5.9.7f) на срабатывании
# comm=grafana, и qname оказался не DNS-запросом вовсе — TLS ClientHello,
# разобранный dns.bpf.c как DNS-пакет (ключ dns_socket_map был потоковым,
# а не процессным, и подхватывал чужой UDP/53-сокет). Это не "штатный
# длинный резолв" (категория a) и не позитивный контроль (категория b) —
# третьей строчной категории здесь нарочно не заводится: закрывается ссылкой,
# а не записью в реестре, потому что сам вход был битым, а не FP-объектом,
# который стоило бы объяснять построчно. Фикс — 5.9.8a (bpf/dns.bpf.c,
# ключ по (saddr,sport) вместо (saddr,daddr,dport)); критерий 5.9.8a требует
# нулевого прироста всех четырёх long-label правил на idle-часе №2.9.8 —
# если он держится, этот файл про grafana больше не заводится вовсе.
