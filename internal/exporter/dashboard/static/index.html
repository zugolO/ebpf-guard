    Layer-7 visibility

    ebpf-guard observes syscalls, files, connections and DNS — not HTTP request bodies. Application-layer attacks are detected behaviorally (connection frequency, process lineage), not by payload inspection, so a SQLi probe that never spawns a process or opens a file will not raise a content-based alert. See docs/l7-detection-coverage.md.
