# rules/optional — правила вне поставки (Д15, волна 9)

Здесь лежат 46 правил, у которых в поставляемой сборке нет источника событий
(№565, Д19): 34 на `event_type: cloud_audit`, 9 на `gpu`, 3 на `iouring`.
Загрузчик читает каталог правил без рекурсии, поэтому `rules/optional/` не
попадает ни в `go:embed` (`rules/embed.go`), ни в `rules/checksums.sha256`, ни
в пакеты, образ и чарт, и агент не называет их «мёртвыми» при старте.

Включение: скопировать нужные файлы в каталог `rules.path` и включить
коллектор-источник (`collectors.cloudtrail` / `gcp_audit` / `azure_monitor`,
`collectors.gpu`, `collectors.iouring`). Без коллектора правила загрузятся, но
агент назовёт их недостижимыми (`ebpf_guard_rules_unreachable`).

Код коллекторов остаётся в дереве — вне поставки только правила.
